# Credits & licences

## Map + terrain data
- Map data © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors, ODbL.
- Elevation: [Terrain Tiles on AWS](https://registry.opendata.aws/terrain-tiles/) (Mapzen) — USGS 3DEP, SRTM and other public sources.

## LiDAR
- USGS 3D Elevation Program (3DEP), project CA_FEMA_Z4_B2_2018 — public domain — accessed as Entwine Point Tiles from the AWS Open Data `usgs-lidar-public` bucket.

## Aerial imagery
- USGS National Map "Imagery Only" basemap (USGS / NAIP and other public-domain sources) — used offline to derive roof colours, ground colour and tree positions (`tools/aerial.py`).
